What happens after activation

The selected page, URL, visible article content, and chosen cleaning specification are sent directly from Firefox to OpenAI. The visible processing page records the response ID after OpenAI accepts the job. Its Retrieve document button fetches that stored response and creates the selected document locally. An external specification host receives only the request for that file, never your API key or article.
